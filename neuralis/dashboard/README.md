# Neuralis OS — Dashboard

The live window into all four layers. React 19 + Vite 6 + Tailwind v4 + Motion, deployed as a static site on Cloudflare Pages.

## Three views

- **Mind View** — health scores, inner weather, the feelings stream (pillar distribution, sit counts, strength), entities, journals, observations, subconscious state, and the MCP tool library
- **Brain View** — thought injection, semantic search, emergent personality, soul portraits, the knowledge layer, active threads, the engine cron board, Cortex tools, and settings
- **Synaptic Bridge** — live SVG visualization of entity relationships and emotional state

Feature panels live in `src/components/`: `FeelingsPanel`, `KnowledgePanel`, `SoulPanel`, `PersonalityPanel`, `EnginePanel`, and `AuthGate`.

## The dashboard watches; it does not author

`FeelingsPanel` is read-only on purpose. In the NESTeq model the companion logs the feeling, sits with it, and metabolizes it — the human watches. Feelings are written from inside a session via `mind_feel`, `mind_sit`, and `mind_resolve`; `/api/feelings` is GET-only (landscape, surface, recent) and the panel polls every 20s so the window moves without being touched.

`SoulPanel` is the one place the human *is* the gate: portraits are generated by the worker and stay PENDING until validated or rejected here.

## Configuration

The dashboard talks to the worker's REST API.

- **Worker URL** — currently set as `BASE_URL` in [`src/api/client.ts`](src/api/client.ts). Point it at your own worker before building. (If you fork this for public use, make it configurable — a hardcoded URL in a client bundle is fine for a single-user deployment, a leak for anything else.)
- **API key** — entered in the dashboard's settings panel at runtime and kept in localStorage. It is never bundled or committed.

There is no frontend `.env` to fill in. The dashboard holds no provider keys of its own — embeddings and generation happen on the worker.

## Run locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev        # Vite dev server
```

Other scripts: `npm run build` (production build to `dist/`), `npm run preview`, `npm run clean`, `npm run lint` (typecheck).

## Deploy

```bash
npm run build
npx wrangler pages project create neuralis-dashboard   # first time only
npx wrangler pages deploy dist/
```

Then allow the dashboard's origin on the worker:

```bash
echo "https://your-dashboard.pages.dev" | npx wrangler secret put DASHBOARD_ALLOWED_ORIGIN --name your-worker-name
```
